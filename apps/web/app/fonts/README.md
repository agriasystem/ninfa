# Poppins (self-hosted)

`Poppins-{300,400,500,600}.woff2` - the Latin subset of Poppins by the Indian Type Foundry, served
through `next/font/local` (see `app/layout.tsx`): no request to Google Fonts is ever made at
runtime, and the build never needs network access for fonts.

License: SIL Open Font License 1.1 (https://openfontlicense.org). The files were taken unmodified
from the Google Fonts distribution of Poppins.
